# ShopKart-E-commerce-Data-Analysis-SQL
Analyzed e-commerce order data using Microsoft SQL Server to identify business and performance trends.

• Analyzed revenue, profit, orders, customers, payments, and cancellations
• Performed monthly and yearly performance analysis
• Used JOINs, GROUP BY, HAVING, CASE, CTEs, subqueries, and window functions
• Derived business insights from customer and order data
